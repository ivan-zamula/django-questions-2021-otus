# Вопросы и ответы на Django (OTUS, 2021)

[English](README.md) | [Русский](README.ru.md)

Учебное приложение вопросов и ответов на Django: профили пользователей, теги и голосование.

Учебный проект OTUS.

## Получение кода

```bash
git clone https://github.com/ivan-zamula/django-questions-2021-otus.git
cd django-questions-2021-otus
```

## Темы проекта

- Вопросы и ответы: теги, поиск и постраничный вывод.
- Регистрация, вход и профили с аватарами.
- Голосование за вопросы и ответы, выбор принятого ответа.
- Почтовые уведомления о новых ответах.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| [questions](questions) | Вопросы, ответы, теги и поиск |
| [users](users) | Учетные записи и аватары |
| [votes](votes) | Модели голосования и рейтинга |
| [otus_django](otus_django) | Настройки Django и основные маршруты |
| [homework](homework) | Исходное задание и примеры интерфейса |

## Начало работы с кодом

Точка входа — [manage.py](manage.py), конфигурация — [настройки проекта](otus_django/settings.py). Код использует Django, `django-crispy-forms` и Pillow. Для локальной работы нужны версии, совместимые с учебным приложением того периода, и настройки базы данных и почты.

Условия упражнения находятся в [PDF с заданием](homework/homework.pdf). Изображения в `homework/` — примеры интерфейса из учебного задания.
